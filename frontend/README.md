# Frontend

Манс: один dashboard. Подключайтесь к [`docs/API_CONTRACT.md`](../docs/API_CONTRACT.md): список вышек и инцидентов → карточка выбранного инцидента → шаги агента → симуляция бюджета → создание work order. Числа приходят с backend.

До готовности данных Абыла можно использовать начальные fixtures API. В финальном демо отображайте пометку «Синтетические данные / симуляция».
