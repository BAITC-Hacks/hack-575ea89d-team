Открыть OpenStreetMap ↗

Число у маркера — количество инцидентов этой вышки. Географическая карта выбранной вышки открывается в OpenStreetMap в новой вкладке, с передачей её координат; нужен интернет.

Схема показывает все вышки по координатам, без географической подложки. Выберите вышку, затем её инцидент для диагностики. Покрытие и связи между вышками не моделируются.
