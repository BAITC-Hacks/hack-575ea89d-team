На каждом ноутбуке нужен доступ к приватному репозиторию. Новый аккаунт должен быть авторизован в GitHub под пользователем с доступом. PR #4 опубликован, но его объединение в main ожидает подтверждения владельца. Сейчас начинать от origin/codex/beeline-tariff-reset. После merge — от main с Beeline Tariff Campaign Agent. Не начинать от старого проекта/старых PR. Если в main ещё старый проект, проверить ветку codex/beeline-tariff-reset и состояние её PR, не смешивать две версии.

