Оригиналы организаторов проверяются по SHA256 из `docs/organizer_manifest.json`. На Windows, чтобы Git не менял байты исходников в рабочей копии, создавайте чистую копию с отключённым преобразованием окончаний строк:

```bash
git -c core.autocrlf=false clone https://github.com/BAITC-Hacks/hack-575ea89d-team.git
```

Для уже существующего клона `core.autocrlf=false` нужно установить до checkout этих файлов; изменение настройки не восстанавливает байты уже преобразованной рабочей копии. Для точной SHA256-проверки надёжнее отдельный чистый clone с такой настройкой. Официальные материалы не редактировались.

## Что исправлено и как покрыто

- Сравнение submission сериализует обе генерации с явным `lineterminator="\n"`; две сериализации сравниваются как UTF-8 bytes, отдельно от сравнения канонического текста с файлом. `Path.read_text(encoding="utf-8")` нормализует CRLF/LF при чтении, поэтому checkout с CRLF не вызывает ложное несовпадение.
- Общий контрактный тест больше не запрещает пересечение финальных аудиторий: он проверяет общий бюджет/охват с учётом каждого повторного контакта и лимиты каждой кампании. Отдельный тест вызывает официальный `scoring_core.score_campaigns`: одна и та же аудитория контактируется дважды, списываются 4 контакта и 16 у.е., но lift засчитывается один раз на каждого из двух абонентов (650 у.е., net 634 у.е.).
- Demo formatter принимает только конечные JSON-числа; `null`, отсутствующее и некорректное значение отображаются как `—`, не как `+0`. До разбора выбранного файла старые метрики очищаются; ошибки схемы/JSON и ошибки первоначальной загрузки показываются с пустыми метриками.
- JS тесты вызываются из общего `unittest discover`, если доступен Node.js; без Node этот дополнительный тест пропускается. Полный список сценариев также можно запустить отдельно `node demo/app.test.js`.

## Ограничения

Все данные и эффекты синтетические. Успех и положительные mock-результаты не предсказывают судейский балл. Верификация выполнена на Linux/Python 3.14, не на Windows или Python 3.12; Windows-стабильность line endings обеспечена явной сериализацией и описанной настройкой checkout, но здесь на Windows не запускалась. Selenium smoke test использовал JS error/unhandled/console hooks; отдельный native Firefox console-log API Selenium для Firefox недоступен. Платные сервисы и LLM не запускались.

Для локального показа: из корня `.venv/bin/python tools/report.py --seed 42`, затем в отдельном терминале `.venv/bin/python -m http.server 8000`, открыть `http://localhost:8000/demo/`. Неудачный автоматический fetch можно заменить кнопкой «Загрузить report.json».
