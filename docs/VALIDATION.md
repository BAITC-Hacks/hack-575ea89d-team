# Начальная проверка — 2026-09-23

Окружение: Python 3.12, numpy 2.5.3, pandas 2.3.3, Linux. Все проверки выполняются из корня. Это baseline до улучшений трёх ноутбуков.

- `python local_eval.py`: PASS, 12 пилотов, 7 финальных кампаний, чистый mock-результат 2 519 731, стоимость 22 548, контакты 5637.
- `python local_eval.py --runs 10`: 10 из 10 в плюс, минимум 1 882 072, медиана 3 178 575, максимум 3 727 614.
- `python make_submission.py`: создан CSV; повторяемость и совпадение с сохранённым файлом проверяются тестом.
- `python -m unittest discover -s tests -v`: 8 тестов прошли за 2.703 секунды. Проверены оригинальность материалов, лимиты с пилотами, отсутствие пересечения финальных сегментов, воспроизводимость, JSON-отчёт, влияние наблюдений на выбор, отрицательные пилоты и резервирование ресурсов.
- `python tools/report.py --seed 42`: создан artifacts/report.json; он игнорируется Git как генерируемый результат.

Baseline использует фиксированный SMS-подход, не LLM. Нет проверки платных API, NVIDIA/Brev или скрытой среды. Положительные mock-прогоны не являются гарантией финального результата. При дальнейших изменениях агентом ноутбука 3 добавить реальные данные новых проверок; не сохранять старые результаты как будто они относятся к новой версии.
