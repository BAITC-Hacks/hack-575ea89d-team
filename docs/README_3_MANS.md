# Манс — Dashboard

## Зона ответственности

`frontend/`: один экран с вышками, инцидентами, диагностикой, журналом агента, бюджетом, вариантами и work order. Контракт: `docs/API_CONTRACT.md`.

## Сделано 2026-09-23

Ветка: `codex/mans-dashboard`. Реализован dashboard на HTML/CSS/JavaScript без сборщика. Подключены GET /towers, /incidents, /incidents/{id}, /work-orders/{id} и POST /analyze, /simulate, /action.

Интерфейс показывает agent_mode (openai/demo/demo_fallback), фактический журнал ответа, пустой результат анализа и ошибки API. При смене бюджета старый выбор сбрасывается; устаревший ответ симуляции игнорируется. Создание заказа требует отдельного подтверждения, повторные нажатия во время запроса блокируются. Все числовые метрики и цены берутся из API. Есть постоянная пометка «Синтетические данные / симуляция».

Изменены: `frontend/index.html`, `frontend/styles.css`, `frontend/app.js`, `frontend/README.md`, этот файл, `README.md`, `STATUS.md`. Backend и API-контракт не изменялись.

## Запуск и проверка

Запустить backend по корневому README. В другом терминале из корня: `python -m http.server 5173 --bind 127.0.0.1 --directory frontend`. Открыть http://127.0.0.1:5173.

Проверено с настоящим FastAPI в demo-режиме: 4 вышки и 3 инцидента, анализ INC-1042 с 6 инструментами, бюджет 20 млн ₸, Upgrade за 12 млн ₸, создание WO-8821 и его чтение после перезапуска backend. Проверены пустой результат анализа и 404 неизвестного заказа. JS прошёл синтаксическую проверку; desktop просмотрен, при ширине 390 px горизонтального переполнения нет. На отдельном тестовом API ранее проверена защита от устаревшего ответа при смене бюджета.

Географическая карта выбранной вышки открывается отдельной вкладкой OpenStreetMap; схема всех вышек остаётся доступной без внешней подложки. Для OSM нужен интернет, координаты передаются этому сервису только при переходе. Покрытие и топология не выдумываются.
- В сравнении показаны самые дешёвые, быстрые и дающие минимальную прогнозную нагрузку варианты только среди доступных в бюджете. При равенстве показателей перечислены все подходящие решения; нет рейтинга AI-уверенности.

Недействительные фильтры сбрасываются; повреждённое/запрещённое хранилище не ломает dashboard. Решение, подтверждение и результаты симуляции не восстанавливаются: выполняется новый расчёт.
- Прямые ссылки `?incident=INC-1042` и копирование ссылки. URL имеет приоритет над сохранённым выбором; неизвестный ID показывает сообщение, а не чужой инцидент. Коллеге нужны доступный ему адрес frontend и тот же backend; localhost-ссылка работает только на текущем компьютере.
- Индикатор API отражает последний запрос; время загрузки сети — время получения `/towers` и `/incidents` браузером, не время измерения нагрузки. Через 5 минут предлагается обновить данные. Фоновый опрос и повторы `/action` не добавлены.
