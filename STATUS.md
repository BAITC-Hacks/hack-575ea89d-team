## Фактически проверено для исходного baseline

Python 3.12, numpy 2.5.3, pandas 2.3.3, Linux. Установлено в отдельное окружение. Команды выполнялись из корня проекта.

| Проверка | Результат |
|---|---|

| Чистый результат seed 42 | +2 519 731 у.е. на mock |
| Затраты seed 42 | 22 548 из 100 000 у.е., пилоты + финальные кампании |

| python -m unittest discover -s tests -v | 8 тестов прошли |

| Исходные материалы организатора | Все SHA256 совпадают с выданным архивом |

Все цифры относятся только к локальной учебной среде. API OpenAI/NVIDIA не вызывались; баланс и активация кредитов не проверялись. На судействе скрытые эффекты другие.

Строка «Осталось бюджета» в стандартном local_eval относится к состоянию env после пилотов. Окончательные расходы брать из общего результата скоринга. Число «Кампаний» там включает пилоты; лимит 10 относится к возвращаемым финальным кампаниям.

## Что отсутствовало в baseline (адаптивность/каналы теперь реализованы выше)

- Адаптивный размер/распределение пилотов, калиброванная оценка неопределённости.
- Оптимальный выбор разных каналов: baseline всегда SMS.
- Расширенный анализ трафика/потребления и разбиение крупных сегментов.
- LLM-компонент; демонстрационный UI; выступление для защиты.
- Проверка на скрытой судейской среде (она команде недоступна).
