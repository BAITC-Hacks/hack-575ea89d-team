## Зона ответственности

`backend/app/main.py`, `backend/app/schemas.py`, оркестрация агента, инструменты, хранение инцидентов и work orders. Стыки — `docs/API_CONTRACT.md` и функции Абыла в `backend/app/services/`.

## Сейчас

- FastAPI маршруты и схемы запросов созданы.
- `analysis_service.py` содержит цикл OpenAI Responses function calling и честный demo-режим без ключа.
- `agent_tools.py` группирует жалобы по вышке, отдаёт ограниченные примеры текста и предоставляет инструменты сети, инцидентов и решений.
- `incident_service.py` сохраняет создание/назначение/приоритет инцидентов в SQLite. `action_service.py` сохраняет work orders и позволяет читать их по ID.
- Реальный вызов OpenAI пока не проверен с ключом команды. Данные Абыла ещё не подключены; `complaints.json` пуст.
- Добавлен предел 35 секунд на модельный анализ, чтобы оставить время для ответа frontend (его ожидание — 45 секунд). Таймаут переключает API в явно помеченный `demo_fallback`.
