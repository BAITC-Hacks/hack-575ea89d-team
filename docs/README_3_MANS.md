# Манс — Dashboard

## Зона ответственности

`frontend/`: один экран с картой/схемой, списком инцидентов, деталями, журналом агента, вариантами решения, бюджетом и созданием work order. API описан в `docs/API_CONTRACT.md`.

## Сейчас

- Папка frontend и инструкция созданы; интерфейса ещё нет.
- Backend уже отдаёт начальные синтетические ответы по маршрутам контракта.

## Дальше

1. Сделать экран и подключить `GET /towers`, `GET /incidents`, `GET /incidents/{id}`.
2. Кнопкой запуска анализа вызвать `POST /analyze`, показать `agent_steps` и рекомендацию.
3. Изменение бюджета отправлять в `POST /simulate`, выбор решения — в `POST /action`.
4. Показывать только цифры API и пометку «Синтетические данные / симуляция».

## Журнал изменений

После каждой своей сессии добавляй дату, изменённые файлы, результат, проверку и следующий шаг. Обновляй также `STATUS.md` и общий README, если меняется запуск интерфейса.
