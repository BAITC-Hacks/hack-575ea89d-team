# Текущее состояние проекта

Обновлено: 2026-09-23. Интеграция: `codex/final-integration`. В неё включены dashboard Манса `6318c5c`, данные/расчёты Абыла из main `6de9d59` и исправления Рамазана. Main автоматически не изменяется.

## Готово в интеграционной ветке

- Единый запуск `python run.py`, dashboard на `/`, API-документация на `/docs`; адрес API автоматически совпадает с адресом страницы. Отдельный frontend-сервер не нужен.
- Последние 35 вышек, 4200 жалоб и население 12 районов Абыла; его формулы и генератор сохранены. В 60-минутном демо-окне 464 жалобы, в том числе 347 для Tower 17. `demo_age_minutes` применяется только к явно синтетическим записям. Для обычных timestamp исключены будущие записи.
- Валидация формы JSON, существования/области/выбранного incident_id, выполненных инструментов, команды и приоритета. Ошибка провайдера/таймаут/невалидное решение даёт явный `demo_fallback`.
- Анализ привязан к выбранному инциденту; числа и назначения подтверждаются Python.
- Повторные/одновременные `/action` возвращают существующий pending-заказ; исторические дубли не удаляются. Список заказов доступен в API и UI.
- Создание инцидента по новому кластеру сериализовано, чтобы избежать гонки ID и дублей.
- GitHub Actions и автоматические тесты backend/frontend добавлены. После нового push Абыла повторная интеграционная проверка выполняется; окончательные результаты будут записаны ниже.

## Реальные ограничения

- На Brev ранее подтверждены оба работающих systemd-сервиса, demo-анализ и сохранность WO-8821. На момент начала этой интеграции там стоял dashboard `81469b6` и прежние данные. Обновление ещё не выполнено.
- Ключ и модель OpenAI на сервере не заданы. Реальный платный API ещё не проверен; подставной клиент в тестах его не заменяет.
- Все данные и прогнозы синтетические; формулы и ограничения — [DEMO_MODEL.md](docs/DEMO_MODEL.md), [API_CONTRACT.md](docs/API_CONTRACT.md).
- Доступ к Brev через локальный SSH-туннель. Публичного URL/аутентификации нет; жизненный цикл полевых работ и история нагрузки не входят в MVP.
- Windows-путь запуска предусмотрен, но пока не проверен на Windows.
